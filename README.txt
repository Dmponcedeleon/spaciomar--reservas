SPACIOMAR - FORMULARIO Y COMPROBANTE ONLINE

1. Sube estos archivos a GitHub Pages, Netlify o cualquier hosting estático:
   - index.html
   - manifest.json
   - sw.js
   - logo-spaciomar.png

2. Para GitHub Pages:
   - Crea un repositorio llamado spaciomar-reservas
   - Sube los 4 archivos
   - Settings > Pages
   - Source: Deploy from a branch
   - Branch: main / root
   - Guarda y abre el enlace publicado

3. En Android:
   - Abre el enlace en Chrome
   - Menú ⋮ > Agregar a pantalla principal / Instalar app

4. Uso:
   - Completa el formulario de la izquierda
   - Noches y saldo se calculan automáticamente
   - Generar Comprobante actualiza el comprobante
   - Compartir por WhatsApp abre WhatsApp con el resumen
   - Guardar como imagen crea una imagen del comprobante

Condiciones incluidas:
- Check-in 15:00 horas. Check-out 12:00 horas.
- Mascotas previa autorización/pago adicional (se debe informar).
- 1 estacionamiento por cabaña.
- Servicio de tinaja es adicional y según disponibilidad.
- Reserva no es reembolsable.


CAMBIOS V2
- Cabañas disponibles: Cabaña 1 a Cabaña 7 y El Piden.
- Personas: máximo 6.
- Botón "Compartir comprobante": en Android intenta compartir la imagen del comprobante directamente.
- Botón "Guardar como imagen": genera PNG.
- Botón "Guardar como PDF": genera PDF A4.
- Para enviar por WhatsApp, en Android puedes usar "Compartir comprobante" y elegir WhatsApp desde el menú de compartir. El PDF se puede guardar y luego adjuntar desde WhatsApp.

VERSIÓN WHATSAPP
- Botón "Compartir JPG por WhatsApp": genera el comprobante como JPG y abre el menú de compartir de Android.
- Botón "Compartir PDF por WhatsApp": genera el comprobante como PDF y abre el menú de compartir de Android.
- En el menú de compartir, selecciona WhatsApp y luego el cliente.
- Si el navegador no admite compartir archivos directamente, el archivo se guarda y WhatsApp se abre para que puedas adjuntarlo manualmente.
